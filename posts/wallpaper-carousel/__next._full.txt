3c:T980,<h2>需求其实很少</h2>
<p>五张竖版插画，每五秒换一张，作为整站的背景。听上去就是 <code>setInterval</code> 加 <code>opacity</code> 的事。</p>
<p>真做起来，有三个坑。</p>
<h2>坑一：竖图铺满横屏</h2>
<p>插画是 1080×1920 的竖图，桌面是 16:9。<code>background-size: cover</code> 会把画面放大到只露出中间一小条——人物的头被切掉一半，看起来像事故现场。</p>
<p>最后的处理是：<strong>不追求「看见完整的人」，而是让整面墙成为氛围</strong>。图片做 3px 柔焦、轻微提亮，再压一层 26% 的米白纸色。涂鸦的色块还在，但不会抢卡片的注意力。</p>
<h2>坑二：切换时闪黑</h2>
<p>如果直接替换 <code>background-image</code>，浏览器会先清空再加载，中间闪一下底色。</p>
<p>所以改成五层 <code>&#x3C;img></code> 堆叠，一直保持挂载，只切 <code>opacity</code>：</p>
<pre><code class="hljs language-css"><span class="hljs-selector-class">.slide</span> {
  <span class="hljs-attribute">position</span>: absolute;
  <span class="hljs-attribute">inset</span>: <span class="hljs-number">0</span>;
  <span class="hljs-attribute">transition</span>: opacity <span class="hljs-number">1600ms</span> ease-in-out;
}
</code></pre>
<p>1600ms 比切换间隔短很多，交叉淡入淡出就显得很稳。</p>
<h2>坑三：静止的画面很死</h2>
<p>光淡入淡出还是「幻灯片」。给当前帧加一个 16 秒的缓慢放大，从 1.02 到 1.1，观感就活了：</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@keyframes</span> kenburns {
  <span class="hljs-number">0%</span>   { <span class="hljs-attribute">transform</span>: <span class="hljs-built_in">scale</span>(<span class="hljs-number">1.02</span>); }
  <span class="hljs-number">100%</span> { <span class="hljs-attribute">transform</span>: <span class="hljs-built_in">scale</span>(<span class="hljs-number">1.10</span>); }
}
</code></pre>
<blockquote>
<p>关键点：动画只在「当前帧」上挂载，切换时重置，这样五张图各自有独立的呼吸节奏。</p>
</blockquote>
