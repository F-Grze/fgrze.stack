## 不要逐个组件改颜色

模板里有几十个组件，写死了 `text-indigo-600`、`bg-purple-500`、`from-indigo-500` 这样的工具类。一个个改，改到一半就会漏。

Tailwind 4 的 `@theme` 把这些颜色变成了 CSS 变量，于是只要在根上重新定义一次，全站的颜色就跟着变了：

```css
@theme {
  --color-indigo-400: #5b5b66;
  --color-indigo-500: #26262e;
  --color-indigo-600: #14141a;
  --color-pink-500:  #a27a44;
}
```

- `indigo` 收成墨色阶——用于标题、链接、主按钮、激活态；
- `purple` 退成石墨灰——用于次要的数字与描述；
- `pink` 换成黄铜——留给「照片」这类需要一点暖意的计数。

## 暗色模式要能切回去

变量重定义会连暗色模式一起改掉，所以再给 `html.dark` 补一层原始色板：

```css
html.dark {
  --color-indigo-500: #6366f1;
  --color-pink-500: #ec4899;
}
```

切回夜间模式时，霓虹色原样回来，两套主题都成立。

## 表面处理的三条规矩

1. **卡片不能太透**。背景是有花纹的涂鸦墙，透明度低于 0.6 就会脏。
2. **描边要细**。白色描边在浅色底上几乎没有意义，换成 `rgba(16,16,22,0.10)` 的墨线，立刻有了印刷品的骨架。
3. **阴影要收**。深色主题靠阴影做体积，浅色主题靠阴影只会显脏，所以只留一层很浅的落影。

## 最后是纸

页面底色用了一个偏暖的米白 `#f6f4ee`，而不是纯白。纯白会让壁纸显得脏，米白会把壁纸里的冷色往暖里拉一点。
