## 需求其实很少

五张竖版插画，每五秒换一张，作为整站的背景。听上去就是 `setInterval` 加 `opacity` 的事。

真做起来，有三个坑。

## 坑一：竖图铺满横屏

插画是 1080×1920 的竖图，桌面是 16:9。`background-size: cover` 会把画面放大到只露出中间一小条——人物的头被切掉一半，看起来像事故现场。

最后的处理是：**不追求「看见完整的人」，而是让整面墙成为氛围**。图片做 3px 柔焦、轻微提亮，再压一层 26% 的米白纸色。涂鸦的色块还在，但不会抢卡片的注意力。

## 坑二：切换时闪黑

如果直接替换 `background-image`，浏览器会先清空再加载，中间闪一下底色。

所以改成五层 `<img>` 堆叠，一直保持挂载，只切 `opacity`：

```css
.slide {
  position: absolute;
  inset: 0;
  transition: opacity 1600ms ease-in-out;
}
```

1600ms 比切换间隔短很多，交叉淡入淡出就显得很稳。

## 坑三：静止的画面很死

光淡入淡出还是「幻灯片」。给当前帧加一个 16 秒的缓慢放大，从 1.02 到 1.1，观感就活了：

```css
@keyframes kenburns {
  0%   { transform: scale(1.02); }
  100% { transform: scale(1.10); }
}
```

> 关键点：动画只在「当前帧」上挂载，切换时重置，这样五张图各自有独立的呼吸节奏。

## 还有一个小细节

`visibility` 也要跟着切。只改 `opacity` 的话，五张全尺寸图片会同时参与合成，移动端会明显掉帧；把非相邻的帧设为 `hidden`，渲染压力立刻降下来。
